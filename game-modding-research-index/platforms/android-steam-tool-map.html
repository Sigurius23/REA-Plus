1 · Android app analysis: the default package path

These are distinct roles; no single decompiler recovers a complete original project.

01 · package

Inventory the exact install

APK Analyzer inspects APK/AAB contents, manifest, DEX and resources. ADB communicates with devices/emulators; record split packages too.

02 · DEX

Browse code

REA/JADX for agent-assisted or Java-like DEX views. Bytecode Viewer and dex2jar are alternative/specialist paths.

03 · other artifacts

Resources and native code

Apktool for decoded resources/Smali. Ghidra or another native RE suite for `.so` libraries or lower-level bytecode analysis.

04 · running behavior

Runtime / triage

ADB + Logcat, Frida/Objection and MobSF address runtime observation or automated triage; none substitutes for package/code inspection.

Role filter · intentionally not in the analysis-first route

Distinguish an analyzer from a loader, editor, installer, source kit or content-discovery service.

Runtime mod frameworks

Repositories such as BepInEx, MelonLoader, UE4SS, REFramework, me3, and Godot Mod Loader primarily load/run mods. They are not the first-choice static analyzers in this view.

Managers, authoring/publishing and discovery

Mod managers, Steam Workshop/distribution services, creator toolchains and authoring-only projects are separate roles. Examples not mapped as analysis tools include Sollumz authoring, Doom map-authoring projects, public Creator Kits and repository discovery lists such as the UE Modding Tools Databank. They do not fill a binary/asset-analysis gap by themselves.

Artifact transfer utility · aria2 (adjacent, not analysis)

aria2 is a cross-platform command-line downloader for HTTP(S), FTP/SFTP, BitTorrent and Metalink, including multi-source transfers. It can fetch a file from a supplied URL/URI or torrent/Metalink source; it does not inspect APK/DEX, pull an installed package, interpret Steam depots, or provide Google Play/Steam package access. The repository’s latest tagged release is 1.37.0 (2023-11-15), while master had visible commits through 2026-06-25. Its Android README describes a native C++ CLI rather than a regular Java app and cites an NDK r14b-generated binary; that document does not establish current Android-device compatibility.

Compatibility boundary: repository support is bounded by title, executable/package build, store edition, platform/architecture, engine/runtime/backend, archive format and tool release. “Primary” describes tool role, not certification that it works on a particular game.
