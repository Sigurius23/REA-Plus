# Platform-specific scope notes

These pages supplement the catalog's resource categories with platform-focused coverage boundaries. They summarize platform coverage and documented tool roles.

- [Android](android/README.md) — developer-integrated UGC examples plus selected app-analysis references for static inspection, automated triage, and runtime observation; no general app-modification API is established.
- [Android + Steam analysis map](android-steam-tool-map.html) — complete against the current in-scope catalog and finite engine checklist; names and links repositories for Android apps/games and Steam PC code/asset analysis, marks families without a dedicated indexed analyzer, and bounds compatibility by title/build/platform/runtime. The map is included in the project ZIP and checked by the catalog validator for local links and unique IDs.
