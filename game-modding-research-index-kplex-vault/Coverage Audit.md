# Coverage Audit

**Repository path:** `ECOSYSTEM_COVERAGE.md`

This hand-maintained document tracks a finite practical checklist, not every game, release, storefront, or mod. The current validator expects **18 crosswalk rows: 6 Covered, 12 Partial, 0 Open, and 0 Out of scope**. Partial items may retain unresolved title/build/platform details; a Covered disposition does not imply every release is represented.

The catalog's two 2026-10-11 reference-project additions do not change the audit date or any checklist disposition. `scripts/validate_catalog.py` pins the row and status counts. If checklist dispositions change, the document and validator guard must be updated together.

Use the audit for scope and status; use each linked project's own version/platform notes for compatibility boundaries.
