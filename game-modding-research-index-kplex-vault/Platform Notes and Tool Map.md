# Platform Notes and Tool Map

**Repository directory:** `platforms/`

This is a hand-maintained documentation area, separate from the generated category pages:

- `platforms/README.md` — navigation to the platform materials.
- `platforms/android/README.md` — Android scope and selected references.
- `platforms/android-steam-tool-map.html` — a standalone decision map for Android app/game analysis and Steam engine-family analysis, with links to relevant tool repositories.

The HTML map is not generated from `resources.json`. Its scope is bounded to relevant tools and the finite engine checklist represented in the curated index; it is not a claim of universal title/release coverage or a tested compatibility matrix. Compatibility remains specific to title, build, store, platform, and runtime where stated.

The map is now included in the project ZIP. The validator checks its local file targets and IDs; upstream projects remain linked rather than copied into the repository.
