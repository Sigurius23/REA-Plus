# Human-Facing Navigation

The repository has several documentation surfaces with different ownership:

- `README.md` — hand-maintained entry point, project scope, and curated navigation.
- `categories/README.md` — generated category directory; see [[Generated Category Pages]].
- `platforms/README.md` — hand-maintained index into platform-specific notes and the HTML analysis map; see [[Platform Notes and Tool Map]].
- `ECOSYSTEM_COVERAGE.md` — finite checklist and audit dispositions; see [[Coverage Audit]].
- `AGENTS.md` and `CONTRIBUTING.md` — project rules and contributor workflow; see [[Governance and Contribution Flow]].

The main README is not a generated dump of all JSON records. Its catalog URLs are checked for consistency by `scripts/validate_catalog.py`.
