# Using K-Plex

This folder is a K-Plex-ready Obsidian vault. The notes encode repository structure through K-Plex’s default hierarchy properties, `Parent` and `Children`.

## Open the map

1. In Obsidian, open `/home/user/game-modding-research-index-kplex-vault` as a vault.
2. Install and enable K-Plex. The plugin’s documented minimum is Obsidian 1.13.0.
3. Open `Repository Overview.md` as the center note in K-Plex. To focus on taxonomy, center on `Generated Category Pages.md` and view its 21 category children.
4. If the hierarchy-property names were customized in K-Plex settings, map them to the `Parent` and `Children` YAML properties used here.

The source repository remains separate at `/home/user/game-modding-research-index`; source file paths are listed in the notes rather than copied into this vault. This vault has 34 map notes: 13 architecture/workflow notes and 21 category-group notes for the 384-record catalog. It has no individual resource notes.

K-Plex navigates Obsidian notes and their relationships; it does not parse Python code or infer repository architecture on its own. These relationships were authored from the repo’s documentation, canonical JSON, scripts, and workflow.
