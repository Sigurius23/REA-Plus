# Changelog

- Added bounded Android text/binary manifest parsing and DEX identifier-table inspection for registered root-manifest APKs.
- Added local Android APK/Steam install HTML reports with capped raster previews.
- Added Steam appmanifest VDF parsing, per-file install inventory, heuristic engine candidates, and VPK v1/v2 directory-tree metadata inspection.
- Added evidence/coverage operations and MCP tools for Android APK and Steam install analysis.

- Explicitly records unsupported Android decompilation/resource/device layers and unsupported proprietary Unity/Unreal/Godot/Source 2 asset/runtime analysis.
